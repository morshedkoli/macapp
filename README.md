# 🖥️ MacApp Dashboard — MacOS-Style Administrative Dashboard

[![Next.js](https://img.shields.io/badge/Platform-Web_Application-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/Language-TypeScript_|_JavaScript-blue?style=for-the-badge)](https://www.typescriptlang.org/)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)

An administrative dashboard crafted with modern macOS aesthetics, featuring glassmorphism, dynamic widgets, smooth window transitions, and productivity controls.

---

## 🌟 Key Features

- **macOS Visual System**: Frosted glass backdrops, sleek dock navigation, and macOS system icons.
- **Interactive Widgets**: Calendar, system resource monitors, task lists, and quick actions.
- **Customizable Themes**: Dynamic day/night wallpaper transitions and accent color picking.

---

## 🛠️ Technology Stack

- **Framework**: Next.js, React 19
- **Styling**: Tailwind CSS, Framer Motion

---

## 🚀 Getting Started

```bash
# 1. Clone repository
git clone https://github.com/morshedkoli/macappdashboard.git

# 2. Install dependencies
npm install

# 3. Launch application
npm run dev
```
